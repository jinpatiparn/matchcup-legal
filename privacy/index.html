ปรับปรุงล่าสุด 2 ตุลาคม 2569

Match Cup (“เรา”) ให้บริการแพลตฟอร์ม Match Cup สำหรับจัด Open Play Pickleball นโยบายนี้อธิบายว่าเราเก็บ ใช้ และดูแลข้อมูลส่วนบุคคลของคุณอย่างไร ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)

1. ข้อมูลที่เราเก็บ

  • จากช่องทางเข้าสู่ระบบ (LINE, Google หรือ Facebook ที่คุณเลือก): ชื่อ รูปโปรไฟล์ อีเมล (ถ้ามี และคุณอนุญาตในหน้ายืนยันของช่องทางนั้น) และรหัสผู้ใช้ของช่องทางนั้น เราไม่ได้รับรหัสผ่านของคุณ
  • ข้อมูลที่คุณตั้งเอง: ชื่อที่แสดงในสนาม การตั้งค่าบัญชี และ DUPR ID กับคะแนน DUPR (ถ้าคุณกรอก)
  • ข้อมูลการเล่น: อีเวนต์ที่เข้าร่วม ผลการแข่งขัน คะแนนแรงก์ (MC) coin ภารกิจรายสัปดาห์ที่รับรางวัลแล้ว ไอเท็มที่ซื้อ และหน้าตาตัวละครที่คุณแต่ง (เมื่อแต่งแล้ว ภาพหัวตัวละครจะใช้เป็นรูปโปรไฟล์แทนรูปจากช่องทางเข้าสู่ระบบ)
  • ค่าคอร์ตและงานของทีม Host (ในอีเวนต์ที่ตั้งค่าคอร์ต หรือเมื่อคุณอยู่ในทีม Host): ยอดที่จ่าย คืน หรือยกให้ วิธีจ่าย (เงินสด/โอน) ผู้บันทึก และเวลา · บันทึกการทำงานของทีม Host เช่น บันทึกผล เช็คอิน รับเงิน · เราไม่ได้รับหรือถือเงินแทนใคร ทีม Host เก็บเงินเอง ระบบช่วยจดเท่านั้น
  • ก๊วน (เมื่อคุณสร้างหรือเข้าร่วม): ชื่อ ตรา สนามและวันเวลาประจำ คำแนะนำก๊วน ประกาศ สมาชิก และบทบาทในก๊วน
  • ใบสรุปที่คุณแชร์: เมื่อคุณกดแชร์หรือคัดลอกลิงก์ใบสรุปคืนนี้ เราเก็บภาพใบสรุปนั้นไว้ที่ลิงก์ matchcup.co/s/… เพื่อให้คนที่ได้ลิงก์เปิดดูได้ และใช้เป็นภาพพรีวิวของลิงก์ในแอปแชต
  • เพื่อนและแชต (เมื่อคุณใช้): รายชื่อเพื่อน คำขอเป็นเพื่อน รายชื่อที่คุณบล็อก ข้อความและการ์ดที่ส่งถึงเพื่อน ของขวัญที่ส่งและได้รับ และการตั้งค่าความเป็นส่วนตัวของส่วนนี้
  • ข้อมูลทางเทคนิค: หมายเลข IP และประเภทเบราว์เซอร์ของการเข้าสู่ระบบ เพื่อความปลอดภัยของบัญชี

2. เราใช้ข้อมูลเพื่อ

  • ยืนยันตัวตน และรวมหลายช่องทางเข้าสู่ระบบให้เป็นบัญชีเดียวกัน
  • อีเมล ใช้เพื่อยืนยันตัวตนและรวมบัญชีที่เข้าจากหลายช่องทางเท่านั้น ไม่แสดงให้ผู้เล่นคนอื่นเห็น และไม่ใช้ส่งโฆษณา
  • จัดคิว จับคู่ผู้เล่น คำนวณแรงก์ และแสดงประวัติการเล่น ใบสรุป และความคืบหน้าภารกิจของคุณ
  • จดค่าคอร์ตให้ทีม Host และแสดงสถานะการจ่ายของคุณในหน้าอีเวนต์
  • ส่งสรุปผลการเล่นทาง LINE เฉพาะเมื่อคุณเพิ่มเพื่อน LINE Official Account ของเรา (ยกเลิกได้ด้วยการบล็อก)
  • ป้องกันการใช้งานที่ผิดปกติ และปรับปรุงบริการ

3. ใครเห็นข้อมูลของคุณ

  • ผู้เล่นและผู้จัดในอีเวนต์เดียวกัน จะเห็นชื่อที่แสดง รูปหรือตัวละคร แรงก์ และผลการเล่นของคุณ
  • DUPR ID และคะแนน DUPR ที่คุณกรอก แสดงในหน้าโปรไฟล์ของคุณ (ลบได้ที่หน้าบัญชี)
  • ทีม Host ของอีเวนต์ (เจ้าของและ Host ร่วม) เห็นสถานะการจ่ายค่าคอร์ตของผู้เข้าร่วม · บันทึกการทำงานของทีมเห็นเฉพาะทีม Host
  • ผู้ใช้ที่เปิดหน้าก๊วนเห็นชื่อ รูป และแรงก์ของสมาชิก รวมถึงอันดับในก๊วน
  • ใบสรุปที่คุณแชร์ ทุกคนที่มีลิงก์เปิดดูได้ (เราตั้งไม่ให้เครื่องมือค้นหาเก็บ) · ใบสรุปมีชื่อที่แสดงและผลของผู้เล่นคนอื่นในอีเวนต์เดียวกัน เว้นแต่ผู้แชร์เลือก “ซ่อนชื่อผู้เล่นคนอื่นในรูป” · ลบลิงก์ได้เองที่หน้าใบสรุป (แอปแชตที่เคยแสดงพรีวิวไปแล้วอาจเก็บภาพพรีวิวไว้เอง)
  • ผู้เล่นคนอื่นค้นหาคุณได้จากชื่อที่แสดงหรือรหัสเพื่อน (ยกเว้นคนที่คุณบล็อก) · ข้อความแชตเห็นเฉพาะคุณกับเพื่อนคนนั้น · เพื่อนจะเห็นว่าคุณลงชื่ออีเวนต์ไหนบ้าง (จากรายชื่อผู้เข้าร่วมอีเวนต์) แต่ไม่เห็นสถานะของคุณในสนาม
  • ผู้ให้บริการที่ช่วยเราดำเนินงาน เช่น ผู้ให้บริการเซิร์ฟเวอร์และฐานข้อมูล และ LINE สำหรับส่งสรุปผลการเล่น โดยใช้ข้อมูลเท่าที่จำเป็นตามที่เรากำหนดเท่านั้น
  • เราไม่ขายข้อมูลส่วนบุคคลของคุณ

4. ระยะเวลาเก็บ

เราเก็บข้อมูลตลอดที่บัญชียังใช้งาน เมื่อคุณลบบัญชี ข้อมูลบัญชี ช่องทางเข้าสู่ระบบ ข้อมูลการเล่น รายชื่อเพื่อน ข้อความแชตที่คุณส่งและได้รับ รายการค่าคอร์ตของคุณ ใบสรุปที่แชร์ สมาชิกภาพในก๊วน และก๊วนที่คุณเป็นเจ้าของจะถูกลบทันที (อีเวนต์ที่ก๊วนเคยจัดยังอยู่ในประวัติของผู้เล่นคนอื่น · ชื่อคุณในบันทึกการทำงานของทีม Host จะแสดงเป็น “ผู้เล่นที่ลบบัญชีแล้ว”) ภาพใบสรุปที่แชร์จะเก็บไว้จนกว่าคุณจะลบลิงก์หรือลบบัญชี · สำเนาสำรองของระบบจะถูกลบตามรอบภายใน 30 วัน

5. สิทธิของคุณ

คุณมีสิทธิขอเข้าถึงและขอสำเนาข้อมูล แก้ไขข้อมูลให้ถูกต้อง ขอลบข้อมูล ขอให้ระงับหรือคัดค้านการใช้ข้อมูล ขอโอนย้ายข้อมูล และถอนความยินยอมเมื่อใดก็ได้ รวมถึงร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล
