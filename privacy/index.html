นโยบายความเป็นส่วนตัว

ปรับปรุงล่าสุด 23 ตุลาคม 2569 · English

Match Cup (“เรา”) ให้บริการแพลตฟอร์ม MatchCup สำหรับจัด Open Play Pickleball นโยบายนี้อธิบายว่าเราเก็บ ใช้ และดูแลข้อมูลส่วนบุคคลของคุณอย่างไร ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)

1. ข้อมูลที่เราเก็บ

  • จากช่องทางเข้าสู่ระบบ (LINE, Google หรือ Facebook ที่คุณเลือก): ชื่อ รูปโปรไฟล์ อีเมล (ถ้ามี และคุณอนุญาตในหน้ายืนยันของช่องทางนั้น) และรหัสผู้ใช้ของช่องทางนั้น เราไม่ได้รับรหัสผ่านของคุณ · เมื่อเปิด MatchCup ในแอป LINE เราได้รับข้อมูลชุดเดียวกับการเข้าสู่ระบบด้วย LINE ผ่าน ID token ที่ตรวจกับ LINE ก่อนใช้ · เวลาแชร์เข้าแชต LINE คุณเลือกแชตเองในหน้าของ LINE เราไม่เห็นรายชื่อแชตหรือผู้รับ
  • ข้อมูลที่คุณตั้งเอง: ชื่อที่แสดงในสนาม การตั้งค่าบัญชี และ DUPR ID กับคะแนน DUPR (ถ้าคุณกรอก)
  • DUPR (เมื่อคุณกด “เชื่อมกับ DUPR” ที่หน้าบัญชี และล็อกอินในหน้าต่างของ DUPR เอง · MatchCup ไม่เห็นรหัสผ่าน DUPR ของคุณ): DUPR ID ชื่อบัญชี DUPR คะแนนคู่/เดี่ยวที่ DUPR ส่งกลับมา เวลาที่ดึงล่าสุด และรหัสเข้าถึง (token) แบบอ่านอย่างเดียวที่ DUPR ออกให้ ซึ่งเราเข้ารหัสก่อนเก็บ และใช้ดึงคะแนนกับสถานะสิทธิ์ของบัญชีใน DUPR (เช่น บัญชีถูกจำกัดหรือไม่) เท่านั้น · DUPR แจ้งคะแนนใหม่มาเมื่อคะแนนเปลี่ยน และระบบดึงคะแนนใหม่ให้ทุกวันจนกว่าคุณจะยกเลิกการเชื่อม (เปลี่ยนหรือยกเลิกสิทธิ์ที่ให้ MatchCup ได้ใน DUPR ด้วย) · ในอีเวนต์ที่ Host เปิด “ส่งผลเข้า DUPR” เราเก็บสถานะการส่งผลของแต่ละเกม (ส่งแล้ว ส่งไม่ได้ หรือไม่ส่งเพราะอะไร รหัสเกมที่ DUPR ให้ และเวลาที่ส่ง)
  • ข้อมูลการเล่น: อีเวนต์ที่เข้าร่วม เวลาที่ขอเช็คอินและเวลาที่ Host ยืนยันเช็คอิน ผลการแข่งขัน คะแนนแรงก์ (MC) coin ภารกิจรายสัปดาห์ที่รับรางวัลแล้ว ไอเท็มที่ซื้อ และหน้าตาตัวละครที่คุณแต่ง (เมื่อแต่งแล้ว ภาพหัวตัวละครจะใช้เป็นรูปโปรไฟล์แทนรูปจากช่องทางเข้าสู่ระบบ) · ถ้า Host เพิ่มคุณเข้าอีเวนต์เป็น walk-in เราเก็บว่าใครเพิ่ม และเวลาที่คุณกดยืนยันว่าอยู่ที่สนาม (ใช้ตัดสินว่าเกมนับ MC ไหม เพื่อกันการปั่นแรงก์)
  • ล็อคคู่ในอีเวนต์ (เมื่อ Host ล็อคคู่ให้ผู้เล่นสองคนที่อยากเล่นด้วยกัน): เราเก็บว่าสองคนนี้ล็อคคู่กัน ใครเป็นผู้ล็อค และเวลา เฉพาะระหว่างเซสชันนั้น · ลบทิ้งเมื่อ Host จบเซสชันหรือยกเลิกอีเวนต์ หรือเมื่อคนใดคนหนึ่งออกจากอีเวนต์ (ชื่อคู่ที่ล็อคอาจยังอยู่ในบันทึกการทำงานของทีม Host)
  • ค่าสนามและงานของทีม Host (ในอีเวนต์ที่มีค่าสนาม หรือเมื่อคุณอยู่ในทีม Host): ยอดที่จ่าย คืน หรือยกให้ วิธีจ่าย (เงินสด/โอน) ผู้บันทึก และเวลา · บันทึกการทำงานของทีม Host เช่น บันทึกผล เช็คอิน รับเงิน · เราไม่ได้รับหรือถือเงินแทนใคร ทีม Host เก็บเงินเอง ระบบช่วยจดเท่านั้น
  • คลับ (เมื่อคุณสร้างหรือเข้าร่วม): ชื่อ ตรา (ตัวอักษรย่อกับสี หรือรูปประจำคลับที่เจ้าของหรือผู้ดูแลอัปโหลด · เราตัดรูปเป็นสี่เหลี่ยมจัตุรัส และไม่เก็บข้อมูลที่ติดมากับไฟล์รูป เช่น ตำแหน่ง) สนามและวันเวลาประจำ คำแนะนำคลับ ประกาศ สมาชิก ขั้นในคลับ (เจ้าของ ผู้ดูแล Host ประจำ สมาชิก) และบันทึกของคลับว่าใครมอบหรือลดสิทธิ์ใคร โอนคลับ และขึ้นเลเวลเมื่อไร · เลเวลคลับคำนวณจากจำนวนอีเวนต์ สมาชิก และผู้เล่นที่ลงเล่นกับคลับ · ชื่อเล่นที่ทีม Host ของคลับตั้งให้ผู้เล่นไว้ใช้ตอนจัดคิว และระดับฝีมือโดยประมาณที่ทีม Host ของคลับตั้งให้ผู้เล่น (สเกลเดียวกับ DUPR · ใช้จัดคิวและแบ่งทีม · แสดงเป็น ≈ ไม่ใช่ DUPR · จำไว้ในคลับนั้น · ไม่เปลี่ยน DUPR ในโปรไฟล์ของผู้เล่น) · รูป QR รับค่าสนามและข้อความบัญชี (เช่น เลขบัญชี ชื่อบัญชี) ที่ทีม Host ของคลับใส่เอง (เราย่อรูปและไม่เก็บข้อมูลที่ติดมากับไฟล์ · แสดงให้ทีม Host และผู้เล่นที่ยังไม่จ่ายค่าสนามของอีเวนต์ในคลับนั้น ต้องเข้าสู่ระบบจึงเปิดรูปได้ · ลบได้ทุกเมื่อ · ลบคลับแล้วลบตาม)
  • ผู้เล่นที่ Host เพิ่มเอง (คนที่มาเล่นแต่ไม่มีบัญชีหรือล็อกอินไม่ได้): ชื่อที่ Host พิมพ์ ระดับฝีมือโดยประมาณ (ถ้า Host กรอก) และผลการเล่นในอีเวนต์นั้น · ไม่มีอีเมล รูป หรือข้อมูลติดต่อ · ไม่ขึ้นในอันดับหรือการค้นหา · Host ควรใช้ชื่อเล่นที่เจ้าตัวยินยอม
  • ใบสรุปที่คุณแชร์: เมื่อคุณกดแชร์หรือคัดลอกลิงก์ใบสรุปคืนนี้ เราเก็บภาพใบสรุปนั้นไว้ที่ลิงก์ matchcup.co/s/… เพื่อให้คนที่ได้ลิงก์เปิดดูได้ และใช้เป็นภาพพรีวิวของลิงก์ในแอปแชต
  • การ์ดยศที่คุณแชร์: เมื่อคุณกดแชร์รูปยศ ส่งใน LINE หรือคัดลอกลิงก์จากหน้าแชร์ยศ เราเก็บรูปยศ (รูปพรีวิว) พร้อมยศและ MC ตอนแชร์ไว้ที่ลิงก์ matchcup.co/r/… ของคุณ (หนึ่งลิงก์ต่อคน)
  • ตัวละครที่คุณแชร์: เมื่อคุณกดแชร์รูปตัวละคร ส่งใน LINE หรือ Facebook หรือคัดลอกลิงก์จากหน้าแชร์ตัวละคร เราเก็บรูปตัวละคร (รูปพรีวิว) ไว้ที่ลิงก์ matchcup.co/c/… ของคุณ (หนึ่งลิงก์ต่อคน) · รูปและวิดีโอที่คุณบันทึกหรือแชร์เป็นไฟล์สร้างในเครื่องของคุณ ไม่ขึ้นเว็บของเรา
  • เพื่อนและแชต (เมื่อคุณใช้): รายชื่อเพื่อน คำขอเป็นเพื่อน รายชื่อที่คุณบล็อก ข้อความและการ์ดที่ส่งถึงเพื่อน ของขวัญที่ส่งและได้รับ และการตั้งค่าความเป็นส่วนตัวของส่วนนี้
  • คำขอเข้าร่วมและแชตของอีเวนต์ (เมื่อคุณใช้): คำขอเข้าร่วมอีเวนต์ที่ทีม Host ต้องอนุมัติก่อน (เวลาที่ขอ ผลการตอบ และใครในทีม Host ตอบ) · ข้อความและรูปที่ส่งในแชตของอีเวนต์ (เช่น สลิปโอนค่าสนาม · ย่อรูปและตัดข้อมูลแฝงในรูป เช่น ตำแหน่ง GPS ออกก่อนเก็บ) และข้อความล่าสุดที่คุณอ่านแล้ว
  • ห้องแชตของคลับ (เมื่อคุณใช้): ข้อความและรูปที่ส่งในห้องแชตรวมของคลับที่คุณเป็นสมาชิก (ย่อรูปและตัดข้อมูลแฝงในรูปออกก่อนเก็บ เหมือนแชตของอีเวนต์) และข้อความล่าสุดที่คุณอ่านแล้ว
  • รายการแข่งของคลับ (เมื่อคุณสมัคร): ทีมของคุณ (คุณกับคู่ รุ่นที่สมัคร สถานะ ลิงก์/รหัสคำเชิญ และเวลาที่ตอบรับ) · รุ่นที่มีเพดาน DUPR: ค่า DUPR ประเภทคู่ที่ยืนยันกับ DUPR ตอนสมัคร/ตอบรับ (ใช้ตรวจสิทธิ์และจัดมือวาง · ไม่รับค่าที่กรอกเอง) · สาย ลำดับ ผลทุกแมตช์ และอันดับสุดท้าย · ถ้ามีกรรมการนับคะแนน: บันทึกทีละแรลลี่ (ใครได้แต้ม ใครเสิร์ฟ เวลา การขอเวลานอก) ใครเป็นกรรมการ และสถิติที่คำนวณจากบันทึกนั้น · MC และ coin ที่ได้จากรายการ
  • คำขอเข้าคลับส่วนตัว (เมื่อคุณขอ): เวลาที่ขอ ผลการตอบ และใครในคลับตอบ · เจ้าของคลับและผู้ดูแลเห็นชื่อและรูปของคนที่ขอ (รวมคนที่ไม่ได้รับ เพื่อรับภายหลังได้) · อีเวนต์ของคลับส่วนตัวเห็นเฉพาะสมาชิก คนที่ลงชื่ออีเวนต์นั้นไว้ และทีม Host
  • ข้อมูลทางเทคนิค: หมายเลข IP และประเภทเบราว์เซอร์ของการเข้าสู่ระบบ เพื่อความปลอดภัยของบัญชี
  • สถิติการใช้งานและความเร็วของเว็บ (Vercel Web Analytics และ Speed Insights · ไม่ใช้คุกกี้): เมื่อเปิดแต่ละหน้า เว็บส่งที่อยู่หน้า (ตัดส่วนหลังเครื่องหมาย ? ออก และหน้าโปรไฟล์ เพื่อน และลิงก์แชร์จะไม่มีรหัสของใคร) หน้าเว็บที่พาคุณมา (ถ้ามี) ประเภทอุปกรณ์ ระบบปฏิบัติการ เบราว์เซอร์ ประเทศหรือเมืองโดยประมาณ ความเร็วอินเทอร์เน็ตโดยประมาณ และเวลาที่หน้าใช้โหลด · เราไม่ส่งชื่อ อีเมล หรือรหัสบัญชีของคุณไปกับข้อมูลนี้ และดูเป็นยอดรวมเท่านั้น
  • รายงานข้อผิดพลาด: เมื่อหน้าเว็บทำงานผิดพลาด เว็บส่งที่อยู่หน้า (ตัดส่วนหลังเครื่องหมาย ? ออก) ชนิดและข้อความสั้น ๆ ของข้อผิดพลาด และรหัสอ้างอิง มาที่เซิร์ฟเวอร์ของเรา ซึ่งเพิ่มชื่อเบราว์เซอร์และระบบปฏิบัติการแบบคร่าว ๆ กับรุ่นของเว็บ แล้วจดลงบันทึกของเซิร์ฟเวอร์ · ไม่ส่งคุกกี้ และเราไม่ใส่ชื่อ อีเมล หรือรหัสบัญชีของคุณในรายงาน (ข้อผิดพลาดที่เกิดบนเซิร์ฟเวอร์จดแบบเดียวกัน)
  • รายงานผู้เล่น (เมื่อคุณกด “รายงาน” ในแชตหรือหน้าโปรไฟล์ หรือมีคนรายงานคุณ): ผู้รายงาน ผู้ถูกรายงาน เหตุผลที่เลือก ข้อความที่พิมพ์เพิ่ม (ถ้ามี) หน้าที่กดรายงาน (แชตหรือโปรไฟล์) เวลา และผลการตรวจของทีมงาน (ปิดเรื่องเมื่อไร โดยใคร และโน้ตของทีมงาน) · รายงานไม่ได้แนบข้อความแชต
  • การดูแลบัญชีโดยทีมงาน: เมื่อทีมงานปรับ coin หรือระงับบัญชีชั่วคราว เราเก็บจำนวน coin เหตุผล วันเวลาที่ระงับถึง ผู้ทำรายการ และเวลา ไว้ในบันทึกงานของทีมงาน
  • บันทึกการส่งสรุปผลทาง LINE: ทุกครั้งที่ระบบส่งสรุปท้ายเซสชันหรือข้อความของรายการแข่งทาง LINE เราจดว่าเป็นของอีเวนต์ไหน (ถ้ามี) ส่งสำเร็จไหม รหัสตอบกลับจาก LINE (HTTP status) และเวลา · ไม่จดชื่อ รหัสผู้ใช้ รหัส LINE หรือข้อความที่ส่ง
  • การสนับสนุนค่าลูกพิกเคิลบอล (เมื่อคุณสนับสนุนเพื่อรับ coin): แพ็กที่เลือก ยอดเงิน coin ที่ได้ สถานะ และเวลา · จากสลิปที่คุณแนบ เราเก็บแค่เลขรายการของธนาคาร ยอดที่โอน เวลาโอน และเลขพร้อมเพย์ของผู้รับแบบที่ธนาคารปิดบางส่วน (ไม่เก็บชื่อหรือเลขบัญชีของผู้โอน) · รูปสลิปที่ระบบตรวจผ่านเองไม่ถูกเก็บ · รูปสลิปที่ต้องให้ทีมงานตรวจเอง (ซึ่งมีชื่อและเลขบัญชีบางส่วนของผู้โอนตามที่ธนาคารพิมพ์) เก็บไว้จนกว่าทีมงานตัดสิน · ไม่มีใบเสร็จ ประวัติการสนับสนุนดูได้ที่หน้าสนับสนุน

2. เราใช้ข้อมูลเพื่อ

  • ยืนยันตัวตน และรวมหลายช่องทางเข้าสู่ระบบให้เป็นบัญชีเดียวกัน
  • อีเมล ใช้เพื่อยืนยันตัวตนและรวมบัญชีที่เข้าจากหลายช่องทาง · ไม่ส่งให้ DUPR ไม่แสดงให้ผู้เล่นคนอื่นเห็น และไม่ใช้ส่งโฆษณา
  • จัดคิว จับคู่ผู้เล่น (รวมถึงให้คนที่ยังไม่เคยเจอกันในอีเวนต์เดียวกันได้เล่นด้วยกันก่อน โดยดูจากเกมที่เล่นไปแล้วในอีเวนต์นั้น และกระจายคนที่เพิ่งเล่นด้วยกันออกจากกัน) คำนวณแรงก์ และแสดงประวัติการเล่น ใบสรุป และความคืบหน้าภารกิจของคุณ
  • จดค่าสนามให้ทีม Host และแสดงสถานะการจ่ายของคุณในหน้าอีเวนต์
  • ตรวจคะแนน DUPR ของคุณเมื่อคุณลงชื่ออีเวนต์ที่ Host ตั้งขั้นต่ำ DUPR ไว้ และแบ่งทีมให้สูสีเมื่อ Host เลือกโหมดจัดคิวตาม DUPR
  • ส่งสรุปผลการเล่นทาง LINE เฉพาะเมื่อคุณเพิ่มเพื่อน LINE Official Account ของเรา (ยกเลิกได้ด้วยการบล็อก) · รายการแข่งส่งทาง LINE แค่ 3 แบบ: คู่ของคุณตอบรับแล้ว · ประกาศสาย · สรุปผลตอนปิดรายการ (ระหว่างแข่งไม่ส่ง LINE)
  • ดูว่าหน้าไหนมีคนใช้ หน้าไหนช้า และหาสาเหตุเมื่อหน้าเว็บผิดพลาด เพื่อแก้ไขให้เร็ว (จากสถิติการใช้งานและรายงานข้อผิดพลาดในข้อ 1)
  • ดูแลชุมชน: ตรวจรายงาน ปรับ coin ให้ถูกต้อง (เช่น ชดเชยเมื่อระบบผิดพลาด หรือหักเมื่อปั่น MC) และระงับบัญชีชั่วคราวเมื่อทำผิดกติกา · ระหว่างถูกระงับ เข้าร่วมอีเวนต์ เช็คอิน ส่งข้อความ และส่งของขวัญไม่ได้ และไม่แสดงในอันดับ (MC coin และประวัติการเล่นไม่เปลี่ยน) · เจ้าของบัญชีเห็นเหตุผลและวันสิ้นสุดบนหน้าเว็บ และติดต่อเราได้ทาง LINE
  • ดูว่าสรุปผลทาง LINE ส่งถึงหรือไม่ เพื่อแก้ไขเมื่อส่งไม่สำเร็จ (จากบันทึกการส่งในข้อ 1)
  • ตรวจสลิปและใส่ coin ให้เมื่อคุณสนับสนุนค่าลูก: ตรวจว่าเงินเข้าบัญชีของ MatchCup ยอดครบ เวลาโอนอยู่หลังเปิดคำสั่ง และสลิปหนึ่งใบใช้ได้ครั้งเดียว · ถ้าระบบตรวจเองไม่ได้ ทีมงานตรวจกับบัญชีที่รับเงินแล้วตัดสิน และโอนส่วนที่โอนเกินคืนให้
  • ป้องกันการใช้งานที่ผิดปกติ และปรับปรุงบริการ

3. ใครเห็นข้อมูลของคุณ

  • ผู้เล่นและผู้จัดในอีเวนต์เดียวกัน จะเห็นชื่อที่แสดง รูปหรือตัวละคร แรงก์ และผลการเล่นของคุณ
  • ทุกคนที่เปิดหน้าอีเวนต์ระหว่างเซสชันเห็นว่าใครล็อคคู่กับใคร (ไอคอนข้างชื่อ) · ล็อคและปลดล็อคได้เฉพาะ Host ของอีเวนต์ (เจ้าของและ Host ร่วม)
  • DUPR ID และคะแนน DUPR (ที่คุณกรอกเองหรือดึงจาก DUPR) แสดงในหน้าโปรไฟล์ของคุณ พร้อมป้าย “กรอกเอง” หรือ “ยืนยันแล้ว” (ลบได้ที่หน้าบัญชี) · ชื่อบัญชี DUPR เห็นเฉพาะคุณ · ในอีเวนต์ คะแนน DUPR ของคุณ (ที่ยืนยันแล้ว หรือที่คุณกรอกเอง) หรือระดับฝีมือโดยประมาณที่ทีม Host ของคลับตั้งให้ (แสดงเป็น ≈) แสดงท้ายชื่อให้ทุกคนในอีเวนต์และบนจอสนามเห็น
  • ทีม Host ของอีเวนต์ (เจ้าของและ Host ร่วม) เห็นสถานะการจ่ายค่าสนามของผู้เข้าร่วม · บันทึกการทำงานของทีมเห็นเฉพาะทีม Host · ชื่อเล่นที่ทีม Host ตั้งให้ผู้เล่นเห็นเฉพาะทีม Host ของอีเวนต์ในคลับนั้น (ผู้เล่นคนอื่นเห็นชื่อเดิม)
  • ผู้ใช้ที่เปิดหน้าคลับเห็นชื่อ รูป แรงก์ และขั้นในคลับของสมาชิก รวมถึงอันดับในคลับ · บันทึกของคลับเห็นเฉพาะเจ้าของและผู้ดูแลคลับ
  • รูปประจำคลับที่อัปโหลดเปิดดูได้ทุกคนที่มีลิงก์รูปเช่นเดียวกับตราคลับ (แสดงในหน้าคลับ รายการคลับ และหัวอีเวนต์ของคลับ) · อัปโหลดได้เฉพาะเจ้าของและผู้ดูแลคลับ ขอให้ใช้เฉพาะรูปที่คุณมีสิทธิ์ใช้ และไม่ใช้รูปของคนที่ไม่ยินยอม
  • ใบสรุปที่คุณแชร์ ทุกคนที่มีลิงก์เปิดดูได้ (เราตั้งไม่ให้เครื่องมือค้นหาเก็บ) · ใบสรุปมีชื่อที่แสดงและผลของผู้เล่นคนอื่นในอีเวนต์เดียวกัน เว้นแต่ผู้แชร์เลือก “ซ่อนชื่อผู้เล่นคนอื่นในรูป” · ลบลิงก์ได้เองที่หน้าใบสรุป (แอปแชตที่เคยแสดงพรีวิวไปแล้วอาจเก็บภาพพรีวิวไว้เอง)
  • ลิงก์การ์ดยศที่คุณแชร์ ทุกคนที่มีลิงก์เปิดดูได้โดยไม่ต้องล็อกอิน (เราตั้งไม่ให้เครื่องมือค้นหาเก็บ) · หน้านั้นแสดงชื่อที่แสดง รูปโปรไฟล์/ตัวละคร ยศ MC และจำนวนเกมของคุณตามจริงตอนที่เปิด · ลบลิงก์ได้เองที่หน้าแชร์ยศ (ปุ่ม “แชร์ยศ” ในหน้าโปรไฟล์)
  • ลิงก์ตัวละครที่คุณแชร์ ทุกคนที่มีลิงก์เปิดดูได้โดยไม่ต้องล็อกอิน (เราตั้งไม่ให้เครื่องมือค้นหาเก็บ) · หน้านั้นแสดงชื่อที่แสดง ตัวละครและบุคลิกของคุณตามจริงตอนที่เปิด (เฉพาะของที่คุณมีอยู่จริง) · ลบลิงก์ได้เองที่หน้าแชร์ตัวละคร (ปุ่ม “แชร์ตัวละคร” ในตู้เสื้อผ้า)
  • รายการแข่งของคลับ: ชื่อทีม สาย ตาราง ผลทุกแมตช์ สถิติแมตช์ และอันดับ ทุกคนที่เห็นรายการนั้นเห็นได้ (รายการของคลับส่วนตัวเห็นเฉพาะสมาชิก และผู้เล่นในรายการ) · ค่า DUPR ที่ยืนยันแล้วแสดงข้างชื่อในรายการนั้น (เหมือนในอีเวนต์) · ลิงก์คำเชิญ ใครได้ลิงก์ก็ตอบรับเป็นคู่ของคุณได้จนกว่าจะมีคนตอบรับหรือหมดอายุ (เชิญด้วยรหัส MC = เฉพาะคนนั้น)
  • ผู้เล่นคนอื่นค้นหาคุณได้จากชื่อที่แสดงหรือรหัสเพื่อน (ยกเว้นคนที่คุณบล็อก) · ข้อความแชตเห็นเฉพาะคุณกับเพื่อนคนนั้น · ข้อความและรูปในแชตของอีเวนต์เห็นเฉพาะทีม Host และผู้เล่นที่ทีม Host รับเข้าอีเวนต์นั้นแล้ว (รวมคนที่รับเข้าภายหลัง) · ข้อความและรูปในห้องแชตของคลับเห็นเฉพาะสมาชิกคลับ (รวมคนที่เข้าคลับภายหลัง · ออกจากคลับแล้วอ่านไม่ได้) · ทีม Host เห็นคำขอเข้าร่วมของคุณ · เพื่อนจะเห็นว่าคุณลงชื่ออีเวนต์ไหนบ้าง (จากรายชื่อผู้เข้าร่วมอีเวนต์) แต่ไม่เห็นสถานะของคุณในสนาม
  • ผู้ให้บริการที่ช่วยเราดำเนินงาน เช่น ผู้ให้บริการเซิร์ฟเวอร์และฐานข้อมูล (Vercel เป็นผู้ให้บริการเซิร์ฟเวอร์ และประมวลผลสถิติการใช้งาน ความเร็ว และบันทึกของเซิร์ฟเวอร์ให้เรา) และ LINE สำหรับส่งสรุปผลการเล่น โดยใช้ข้อมูลเท่าที่จำเป็นตามที่เรากำหนดเท่านั้น
  • DUPR (เมื่อคุณกด “เชื่อมกับ DUPR”): คุณล็อกอินกับ DUPR เอง แล้ว DUPR ส่ง token ให้เรา เราส่ง token นั้นกลับไปที่ DUPR เพื่อยืนยันว่าเป็นบัญชีของคุณและดึงชื่อกับคะแนน (ไม่ส่งอีเมลหรือข้อมูลอื่นของคุณให้ DUPR) · ในอีเวนต์ที่ Host เปิด “ส่งผลเข้า DUPR” เมื่อจบเซสชัน เราส่งผลของเกมที่ผู้เล่นทุกคนในเกมเชื่อม DUPR แบบยืนยันแล้วให้ DUPR: DUPR ID ของผู้เล่นในเกม สกอร์ วันที่ สถานที่ ชื่ออีเวนต์ สนาม และประเภทคู่/เดี่ยว (ไม่ส่งอีเมลหรือชื่อ) · แก้หรือยกเลิกผลหลังส่ง เราแจ้ง DUPR ให้แก้หรือลบตาม · ยกเลิกการเชื่อม DUPR แล้ว เกมของคุณหลังจากนั้นไม่ถูกส่ง · ข้อมูลที่ DUPR ถืออยู่เป็นไปตามนโยบายของ DUPR
  • ทีมงาน MatchCup (เฉพาะผู้ดูแลระบบที่เรากำหนด) ดูข้อมูลบัญชีของคุณได้เพื่อดูแลผู้ใช้: ชื่อที่แสดง รหัสเพื่อน วันที่สมัคร ช่องทางเข้าสู่ระบบที่เชื่อมไว้ (เฉพาะชื่อช่องทาง) แรงก์ เกมล่าสุด coin และประวัติ coin รายงานที่เกี่ยวกับคุณ และบันทึกงานของทีมงาน · ทีมงานปรับ coin (คุณเห็นรายการพร้อมเหตุผลในประวัติ coin) และระงับบัญชีชั่วคราวได้ · หน้าดูแลผู้ใช้ไม่แสดงอีเมล token หรือข้อความแชตของคุณ
  • รายงานผู้เล่นเห็นเฉพาะทีมงาน · ผู้ถูกรายงานไม่เห็นรายงานและไม่รู้ว่าใครรายงาน
  • SlipOK (บริการตรวจสลิป) เมื่อคุณแนบสลิป: เราส่งรูปสลิปให้ SlipOK อ่าน QR บนสลิปและตรวจรายการกับธนาคาร แล้วส่งผลกลับมา · ข้อมูลที่ SlipOK ประมวลผลเป็นไปตามนโยบายของ SlipOK · เจ้าของบัญชีพร้อมเพย์ที่รับเงิน (ทีมงาน MatchCup) เห็นชื่อผู้โอนในรายการเงินเข้าของธนาคารตามปกติของการโอนเงิน · ทีมงาน MatchCup เห็นคำสั่งสนับสนุนของคุณ (ชื่อที่แสดง แพ็ก ยอด สถานะ) และรูปสลิปที่รอตรวจ
  • เราไม่ขายข้อมูลส่วนบุคคลของคุณ
